A deterministic program that writes a single one-line, 1-star review from a houseplant about its human owner — "One Star, Written in Sap" — to `/output/entry.txt`. Standard library only, no network, no randomness: every run produces the same 219-character line.

## Run it

```sh
python3 main.py
```

The program writes the review to `/output/entry.txt` (pass a different path as the first argument to write elsewhere, e.g. `python3 main.py /tmp/entry.txt`).
